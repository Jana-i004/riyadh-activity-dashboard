# Riyadh Activity Dashboard 🇸🇦

An interactive dashboard that analyzes city activity patterns in Riyadh, Saudi Arabia.

## 📊 Overview

This project explores how different real-world factors influence daily activity levels in Riyadh, including:

* 🎉 Events
* ⚽ Football matches
* 💰 Salary timing
* 📅 Weekends
* 🎊 Public holidays
* 🌦 Weather conditions (Rain, Dust, Fog)

## 🇸🇦 Why This Matters

This dashboard is built using **Saudi-specific data**, reflecting real behavioral patterns in Riyadh, such as:

* Salary cycle impact (around the 27th)
* Weekend structure (Thursday–Saturday)
* Local events and entertainment seasons
* Environmental factors like dust storms
